# Tribute Page: Abd al-Rahman I (The Falcon of Quraysh)

A responsive tribute page dedicated to Abd al-Rahman I, the Umayyad prince who escaped the Abbasid massacre and founded the Emirate of Córdoba in Al-Andalus.

Built as **Task 2** of the Web Development track at Oasis Infobyte (OIBSIP).

## Live Demo
https://marrutantawy.github.io/OIBSIP/WebDev-Task2-TributePage/

## Features
- Title with the subject's name (English and Arabic) and a one-line tagline
- Prominent hero image of the Great Mosque of Córdoba (Wikimedia Commons)
- Four-paragraph biography written in my own words, with a side image
- Timeline of key moments built with an ordered list
- Distinct styled quote block
- Four different section background colours
- Two font families: Marcellus (headings) and Source Sans 3 (body)
- Fully responsive layout using CSS Grid and media queries

## Tech Stack
HTML5, CSS3 (no JavaScript, no frameworks)
